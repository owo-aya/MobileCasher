[b]手机收款 / MobileCasher[/b]

让手机通过局域网接收游戏的到账消息，并播放到账语音，更加有收钱的感觉！

页面中的收款界面和金额均为手搓，播报的各种设置都沿用前置模组，只是把语音改成了手机播放。

[h1]主要功能[/h1]

[list]
[*][b]手机到账播报[/b] 游戏内收到收入后，通过手机播放前置模组的到账语音。
[*][b]顾客信息与实际金额[/b] 显示对应顾客的头像、名字和到账金额。
[*][b]支付宝与微信界面[/b] 根据前置模组设置显示对应的平台。
[*][b]深浅色适配[/b] 页面跟随手机系统主题切换深色和浅色。
[*][b]游戏内扫码连接[/b] 在模组的设置页面查看二维码（你也可以手动输入网址）、连接地址和状态。
[/list]

[h1]前置模组[/h1]

需要订阅并启用「到账语音播报 / Announce the Transaction」，当前适配版本为 [b]1.1.1[/b]。

[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3831162516]点击前往前置模组的创意工坊页面[/url]

[h1]使用方法[/h1]

[olist]
[*]在创意工坊订阅并启用本模组和前置。
[*]打开游戏菜单中的「改装件」，阅读权限提示，审核并启用两个模组，然后重启游戏。
[*]让手机和电脑连接到能够互相访问的同一局域网。
[*]打开「改装件」（入口在游戏原生的「改装件」页面中），进入模组设置页面查看二维码。
[*]手机扫码后，点击页面上的「开始收款」，连接完成后进行游戏内交易即可。
[/olist]

[h1]权限说明[/h1]

游戏弹出的权限警告请认真阅读，以下是这些权限的用途。警告上说的那些权限都是真的！如果我想干坏事是真的可以做到的！
[list]
[*][b]网络访问[/b] 在电脑上提供局域网 HTTP 服务，让手机读取收款页面、语音和游戏到账数据，二维码在电脑本地生成。
[*][b]外部反射[/b] 读取已加载前置模组的播报设置、调用金额语音序列生成逻辑，并接管电脑端的到账播报。
[/list]

游戏授予的权限范围实际更广，请根据你对模组的信任程度决定是否启用。

手机网页资源随模组内嵌，前置语音通过游戏提供的受限接口读取，当前版本已移除文件访问权限。

[b]建议在可信局域网中使用。[/b] 当前连接采用 HTTP 明文传输，尚未加入配对鉴权，能够访问电脑服务端口的其他设备也可以读取游戏收款记录。连接数量上限和请求总时限仍待完善。

[h1]常见问题[/h1]

[b]我想调整播报设置。[/b]
打开前置「到账语音播报」自己的游戏内配置进行调整。

[b]扫码后打不开页面。[/b]
确认手机和电脑在局域网中能够互相访问，并留意 Windows 对游戏入站连接的提示。代理、VPN 或 TUN 可能影响路由，校园网的访客网络也可能启用设备隔离。

[b]页面打开了，手机却没有声音。[/b]
点击「开始收款」，开启手机媒体音量，并保持页面在前台。

[b]页面打开了，手机有两层播报声。[/b]
看看是不是扫码客户端和浏览器同时连上了。

[b]可是我真的很想有钱转账进来。[/b]
吸点梦尘吧。
