# 手机收款 / MobileCasher

让手机通过局域网接收《Probably Stolen》的到账消息，显示游戏顾客的头像、名字和实际交易金额，再播放支付宝或微信的到账语音。

[下载安装包](https://github.com/owo-aya/MobileCasher/releases)

## 安装

1. 订阅并启用前置「到账语音播报 / Announce the Transaction」，当前适配版本为 1.1.1。[前置创意工坊页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3831162516)
2. 在 Releases 下载 MobileCasher-v0.3.3.zip，将其中的 Mods 和 MobileCasherPhone 文件夹解压到 Probably Stolen.exe 所在目录。
3. 在游戏的「改装件」中阅读权限提示，审核并启用本模组，按游戏提示重启。
4. 手机和电脑连接同一局域网，在本模组设置页扫描二维码。
5. 在手机浏览器点击「开始收款」，保持页面在前台，再进行游戏内交易。

微信、QQ 内打开时会显示浏览器打开提示，完整链接支持复制。切换网络后，可在模组设置页点击「刷新连接」。

## 功能

- 手机显示顾客头像、名字、游戏实际到账金额和对应平台的模拟收款界面。
- 支付宝与微信平台选择、音量和语速沿用前置模组设置。
- 页面跟随手机系统深浅色主题。
- 到账语音由手机播放，电脑端的到账播报由本模组接管。
- 二维码、实际连接地址和连接状态显示在游戏原生模组设置页。

## 权限与安全

当前版本声明 network、files 和 reflection-external，用于局域网通信、读取网页及前置语音文件、对接前置播报逻辑。

当前服务使用 HTTP 明文传输，尚未加入配对鉴权。能够访问该端口的其他设备也可以读取游戏收款记录。连接数量上限和请求总时限仍待完善，建议在可信局域网中使用。
